## Kluczowe zmiany w v4 vs v3

- Pivot filozoficzny: z "jak sprzedawać" na "jak ja kupuję" — perspektywa kupującego
- 5 modeli współpracy jako osobne ścieżki z odrębnymi kryteriami oceny i added value
- Konkretne oczekiwania "co chciałbym" w modelach Managed Team i T&M/FP — Lead z listą wymagań, analiza repo, steering committee, transparentność, ramp-up 2-6 tyg, engineering practices
- Domeny: logistyka i bankowość jako konkretny kontekst
- Format: 2h + 15 min case study + 1h konsultacji per zespół (5-6 zespołów)
- Case study na żywo z real-time feedbackiem kupującego
- Ton: "tak ja to widzę" zamiast "tak powinniście robić"
